# Kotlin + Jetpack Compose Android Template

A modern, minimal Android starter template built with **Kotlin** and **Jetpack Compose**.  
It's designed for anyone who wants to start a new Android project quickly, with a clean architecture and automated builds using GitHub Actions.

## Features

- ✅ **Kotlin** – fully typed, concise, and modern
- ✅ **Jetpack Compose** – declarative UI, no XML layouts
- ✅ **Material 3** – modern design components
- ✅ **Light/Dark theme toggle** – one-button switch
- ✅ **Customizable app icon** – vector drawable ready
- ✅ **GitHub Actions** – automatic build of `debug.apk` and `release.aab`
- ✅ **Release signing** – uses GitHub Secrets for keystore
- ✅ **Minimal and beginner-friendly** – easy to understand and extend
